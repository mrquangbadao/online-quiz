# .codex

This folder stores project-specific context, rules, workflows, and prompt templates for Codex.

## Layout
- `context/`: stable repository and domain context.
- `rules/`: implementation constraints by area.
- `workflows/`: repeatable task execution patterns.
- `templates/`: prompt templates for common requests.

## Usage
- Keep `AGENTS.md` short and stable.
- Put detailed instructions here instead of expanding `AGENTS.md`.
- Update these files when the codebase or team conventions change.
